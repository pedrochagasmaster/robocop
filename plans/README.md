## Findings considered and rejected

These were surfaced by the audit but not promoted to plans, with reasoning so
nobody re-audits them next run:

- **Legacy Windows/PowerShell GUI reintroduction** — ADR-0001/0002/0003 settle
  the server-side TUI direction; the legacy GUI is hard-deleted at v1.0. Not a
  finding.
- **`--download` dead path in `Query_Impala_Parametrized.py`** — ADR-0003 names
  it as dead code post-v1.0, but the audit confirmed it is **already gone**
  from `scr/Query_Impala_Parametrized.py` (no `--download`/`export_table_to_csv`
  references). Not a finding.
- **`scr/` stdlib-only policy** — ADR-0005 settles it; do not recommend adding
  libraries to `scr/`.
- **Textual 8.2.5 pin lag** — ADR-0002 deliberately pins pre-1.0 with frozen
  vendored deps; upgrading is an infrequent deliberate act. Not a finding.
- **Mock fakes accepting any credentials** — ADR-0004 explicitly states mocks
  are not a security boundary. Not a finding.
- **`manifest.update` load-modify-write non-atomicity** — single writer (the
  detached runner); the TUI only reads. Not a concurrency bug.
- **`_replace_manifest` PermissionError retry** — Linux `rename(2)` is atomic;
  the retry is a Windows-dev courtesy. Not a bug.
- **Kerberos `parse_ttl_seconds` naive datetime** — `klist` emits naive
  local-wall timestamps and the parser uses naive `datetime.now()`; the
  subtraction is consistent. Not a bug in practice.
- **`cycle_through_pools` infinite retry in `scr/`** — intended per ADR-0005
  (frozen retry timing). Not a bug.
- **Mid-Job Kerberos auto-renewal** — ADR-0001 forbids the TUI from owning
  lifecycle; the dashboard already surfaces TTL and `kinit` is palette-reachable.
  Not a direction.
- **Auto-queueing a 3rd Job when 2 slots are full** — `CONTEXT.md` and the
  legacy plan explicitly settle this as "hard refuse only". Re-litigating a
  settled decision.
- **Per-month CSV export for `SqlTemplate`** — `CONTEXT.md:73-75` settles
  `SqlTemplate → Table` only. The user can export a produced table via
  `ExistingTable → Csv` (DIRECTION-03).
- **Dark/light theme, plugin system, AI SQL, job tags/labels** — no ADR, no
  doc promise, no code hook grounds these for this user base. Rejected as
  ungrounded direction noise.
- **Cross-user Job visibility / cluster-health dashboard** — out of v1.0
  scope per legacy plan; no ADR or code hook invites them back.
- **`history.HistoryScreen.refresh_history` dead code** — noted by the
  correctness auditor as tech-debt (defined but never called). Not promoted
  because it's a one-line delete with no behavioral impact; fold into the
  first history-touching plan.
