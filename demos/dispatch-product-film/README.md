# Dispatch product film

A 15-second, 1080p Remotion film introducing Dispatch with a restrained,
product-first visual language: dark glass, generous typography, deliberate
motion, and a single violet accent. The UI is a stylized representation rather
than a recording, so the film stays legible and polished at presentation scale.

## Preview and render

Requires Node.js 20 or newer.

```bash
npm install
npm run preview
npm run render
```

The rendered film is written to `out/dispatch-film.mp4`. Render output and
dependencies are intentionally ignored; only the reproducible source belongs
in version control.
